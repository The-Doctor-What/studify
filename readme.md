# Studify — Каталог онлайн-курсов (Тестовое задание для 10X)

Привет! 👋 Это реализация тестового задания на позицию Frontend-разработчика. Проект представляет собой интерактивный карточный каталог с фильтрацией и живым поиском.

🔗 **[Смотреть Demo на Vercel](https://studify-seven-eta.vercel.app/)**
🔗 **[Исходный код на GitHub](https://github.com/The-Doctor-What/studify)**

---

## 🛠 Технологии и стек

Согласно требованиям, проект выполнен без использования UI-фреймворков:
* **HTML5** (Семантическая разметка).
* **SCSS / CSS3** (Строго по методологии **БЭМ**).
* **Vanilla JavaScript** (ES6+, модульная структура).
* **Vite** — использован в качестве сборщика для удобной работы с модулями, SCSS и быстрой подготовки production-сборки.
* **ESLint** (Flat Config) — для поддержания чистоты и стандартов кода.

## ✨ Реализованный функционал

1. **Pixel-perfect и "резиновый" адаптив:** Сетка каталога реализована с помощью современных возможностей `CSS Grid` (`grid-template-columns: repeat(auto-fill, minmax(...))`). Это позволило сделать интерфейс полностью "резиновым" от 1920px до 320px **без использования жестких медиазапросов**. Карточки плавно перестраиваются и масштабируются.
2. **Синхронная фильтрация и поиск:** * Поиск по названию работает "вживую" (на событии `input` без перезагрузки страницы и учета регистра).
    * Поиск и фильтрация по категориям работают в связке, используя единый глобальный state в JavaScript.
3. **Mock-Data:** Данные курсов вынесены в отдельный модуль (`data.js`) для удобства поддержки и имитации работы с реальным API. Скрипт динамически рендерит карточки на основе массива данных.
4. **Динамические счетчики:** Количество курсов в кнопках фильтров высчитывается скриптом автоматически на основе длины отфильтрованного массива.

## 🚀 Как запустить проект локально

Убедитесь, что у вас установлен Node.js и pnpm (или npm/yarn).

1. Клонируйте репозиторий:
   ```bash
   git clone <ваша-ссылка-на-репо>
   ```
2. Перейдите в папку проекта:
   ```bash
   cd studify
   ```
3. Установите зависимости:
   ```bash
   pnpm install
   ```
4. Запустите dev-сервер:
   ```bash
   pnpm run dev
   ```
5. Для проверки линтером:
   ```bash
   pnpm run lint
   ```
6. Для сборки production-версии:
   ```bash
   pnpm run build
   ```

## 📈 Что можно было бы улучшить (Планы на развитие)

Задание выполнено в рамках оговоренного времени, но если бы это был реальный боевой проект, я бы добавил:

1. **Debounce для поиска.** Сейчас фильтрация массива происходит при каждом вводе символа. В рамках локальной заглушки это работает мгновенно, но при реальных запросах к серверу (API) нужно добавить функцию-задержку (debounce), чтобы не спамить бэкенд запросами.
2. **Скелетная загрузка (Skeleton Loader).** Добавить анимацию загрузки (placeholder) на время, пока подгружаются картинки или запрашиваются данные курсов, чтобы избежать "прыжков" верстки.
3. **Пагинация / Lazy Load.** В случае увеличения базы курсов стоит реализовать кнопку "Показать еще" или бесконечный скролл с использованием `Intersection Observer`.
